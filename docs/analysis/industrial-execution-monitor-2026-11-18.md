# Industrial Execution Monitor pilot — evidence review, 18 November 2026

The pilot compares 10X in Northlake, Narva Phase 1A and the initial Stillwater magnet operation. The update and evidence cutoff are both 18 November 2026. Sources listed below were checked for this draft through that cutoff. Dates in the source column are release or filing dates. Dates in the claim column describe the event or the issuer’s target, at the precision the source supports.

The display attributes progress to the issuer or filing. SMPT’s assessment concerns the kind of evidence that would advance each case. It does not infer production from a designated project, a financing award, an offtake agreement or planned capacity.
