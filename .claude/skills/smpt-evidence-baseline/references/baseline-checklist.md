# Baseline checklist

Mark each PASS, FIX or N/A with a note. An unresolved FIX is carried forward as a limitation, not dropped.

## Sources
- [ ] Cutoff stated; post-cutoff sources excluded or flagged.
- [ ] Every source has issuer, date, locator precise enough to find the figure (page, section, table, exhibit).
- [ ] Primary used wherever one exists; secondary only points to it.
- [ ] Original language and translation provenance kept for non-English quotations.
- [ ] Issuer statements attributed to the issuer ("MP Materials reports…"), not stated as fact.

## Figures
- [ ] Each figure has unit, currency (original), period and as-of date.
- [ ] Each figure has a class: reported, derived, modeled or judgment.
- [ ] Each money figure has a role (ceiling, committed, drawn, spent, ended) and instrument.
- [ ] No sum across currencies, instruments, roles or parent/child records.
- [ ] Gross versus net, pre- versus post-fee, fiscal versus calendar period stated.
- [ ] Percentages name their numerator and denominator.

## Links and identity
- [ ] Each cross-layer link is a hypothesis with mechanism, timing, counter-evidence and a competing explanation.
- [ ] Entities resolved (aliases, parent/subsidiary, borrower/guarantor); no invented relationship.
- [ ] Tracker records cited by ID; none edited.

## Gaps
- [ ] Gaps listed with their effect on the decision and their treatment.
