# Engagement mandate

Copy into the product folder as `MANDATE.md`. Every field is filled or marked `open` with the reason.

| Field | Entry |
| --- | --- |
| Product ID / version | |
| Decision-maker | Real organization **or** "Hypothetical perspective: …" |
| Commissioning statement | "Independent SMPT analysis; not commissioned or endorsed by any named party." |
| Decision (one sentence, answerable) | |
| Alternatives in scope | At least two, including "do nothing / wait" where credible |
| Horizon | |
| Constraints | Budget, legal, timing, governance, risk appetite |
| Outcome measure | What "better" means for this decision-maker (cash, security of supply, timing, optionality, risk) |
| Economic mechanism (hypothesis) | How policy / capital / execution plausibly reach the outcome measure |
| Evidence cutoff | Date; inherited from `…` or newly set |
| Holds / frozen inputs | Publication hold, frozen model, embargoed source — with file paths |
| Product format | Memo / deck / deck + workbook — with reason |
| Out of scope | And why |
| Human reviewer | Name or `PENDING` |

## Decision test

- [ ] The answer changes what the decision-maker does.
- [ ] The question is answerable with yes / no / which / when / how much.
- [ ] Rejected framings are recorded with reasons.
