# Issue tree and hypotheses

## Tree

```
Decision: …
├── 1. [Branch]  (layer or value driver)
│   ├── 1.1 [Leaf question]  → evidence type → owning skill
│   └── 1.2 …
├── 2. …
└── 3. …
```

Branch tests: mutually exclusive (each branch asks a distinct analytical question, so no question sits in two branches), collectively exhaustive (together the branches cover everything the decision depends on), 3–5 branches. MECE governs the questions and their coverage, not the evidence. One source can inform several branches, for example a filing that states both financing terms and capacity. Cite it in each branch it informs.

## Worked example (structure only)

Decision: "Should a strategic offtaker take a minority equity stake in a US magnet producer now, or wait for commissioning evidence?"

1. Policy — are the government supports binding, and on what conditions? (`smpt-evidence-baseline`)
2. Capital — what is committed versus drawn, and who bears the first loss? (`smpt-financing-structure`)
3. Execution — what stage has the facility actually reached? (`smpt-evidence-baseline`)
4. Commercial — what does each option return under the base and downside cases? (`smpt-investment-appraisal`, `smpt-options-decision`)
