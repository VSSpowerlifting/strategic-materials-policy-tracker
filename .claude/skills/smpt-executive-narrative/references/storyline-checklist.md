# Storyline checklist

Mark PASS, FIX or N/A.

- [ ] Input contract complete (question, audience, source register, cutoff, model checks, rights) or gaps recorded.
- [ ] Executive judgment answers the question first and cites its decisive facts.
- [ ] Titles are complete claims; title-only read forms a defensible argument.
- [ ] One distinct insight per analytical slide; no duplicated findings.
- [ ] Length within the product budget, counting every slide.
- [ ] Each slide spec names the comparison the exhibit exposes and the data path behind it.
- [ ] Exhibit families vary by question; tables kept where precision needs them.
- [ ] Evidence, calculation, scenario and judgment visibly distinguished.
- [ ] No causal verb (drove, caused, triggered) without supporting evidence; temporal or shared-material links stated as such.
- [ ] Status words (announced, committed, drawn, disbursed, operating) match the evidence.
- [ ] Affirmative, specific prose; material factual negations kept.
- [ ] Handed to `smpt-review-gate`; no readiness claim made here.
