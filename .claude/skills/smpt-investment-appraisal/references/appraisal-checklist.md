# Appraisal checklist

Mark PASS, FIX or N/A.

- [ ] Question written as a threshold test tied to a named decision.
- [ ] Every input in the register with class, unit, period, source/rationale and range.
- [ ] Discount rate stated with its basis; nominal/real consistent with cash flows.
- [ ] Origin year and timing convention (end-of-year) stated.
- [ ] Numbers computed by the script or a checked workbook; payloads retained.
- [ ] Threshold described as "what would have to be true", not output, demand or a forecast.
- [ ] Non-positive margin reported as n.a., not forced.
- [ ] IRR, if shown, accompanied by its cash-flow pattern and any script warnings.
- [ ] Sensitivities one-at-a-time across stated ranges; at most three named scenarios.
- [ ] Units and conversions explicit (t vs lb, oxide vs metal, $/t vs c/lb).
- [ ] Display rounding only; sums recomputed from unrounded values.
- [ ] Modeled figures labelled wherever they appear, including chart labels and footnotes.
- [ ] Independent check of each headline output recorded.
