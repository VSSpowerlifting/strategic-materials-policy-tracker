# Hard holds

Source: `docs/design/presentations/EDITORIAL_AUTHENTICITY_AND_VISUAL_INTEGRITY.md` §5 and `docs/research/SMPT_APPLIED_STRATEGY_STANDARD.md` §5. Any item below makes the overall outcome HOLD.

| Hold | What to look for |
| --- | --- |
| Fabricated or unsupported material claim | Source not in register, URL that does not resolve to the cited content, quote absent from the original |
| Incorrect material figure | Recomputed value differs beyond display rounding; units or currency mislabelled |
| Irreconcilable exhibit | Chart values do not match the workbook or the bridge does not close |
| Misclassified financing status | Commitment shown as drawn, facility shown as cash, expired instrument shown as live |
| Scenario shown as observed | Modeled or threshold value presented as forecast, output or outcome |
| Misleading geometry or implied causality | Truncated axes without notice, area distortion, arrows or sequencing that assert causation the evidence lacks |
| Rights violation | Reproduced third-party figure or screenshot without permission |
| Missing material assumption | Discount rate, phasing, price or conversion basis not stated |
| Missing human publication authorization | Always true for an agent review; this is why the ceiling is READY FOR HUMAN PUBLICATION REVIEW |

The last row does not make the agent's assessment HOLD by itself; it is the reason the agent cannot go beyond READY FOR HUMAN PUBLICATION REVIEW. All other rows do.

A valid caveat, cautious qualifier or justified visual pattern never triggers a hold because it resembles a writing tell.
